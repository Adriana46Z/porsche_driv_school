## About the Project
The Porsche Driving School platform was developed to bridge the gap between traditional driving instruction and modern digital management. It offers a sophisticated environment where students can book sessions, track their progress, and interact with top-tier instructors—all within an interface that reflects the sleek aesthetics of the Porsche brand.

## Key Features

* **Dashboard Tracking:** Visual statistics and progress reports for students.
* **Interactive Quizzes:** Mock exams to prepare for the official theoretical test.
* **Resource Management:** Easy access to traffic laws and educational materials.
* **Role-Based Access:** Dedicated interfaces for Admins, Instructors, and Students.
* **Engagement Section:** A community meme section to keep the learning experience light.

## Installation & Setup

1. **Clone the Repository**
    ```bash
    git clone [https://github.com/Adriana46Z/porsche_driv_school.git](https://github.com/Adriana46Z/porsche_driv_school.git)
    ```

2. **Environment Setup**
    * Move the project to your local server
    * Ensure PHP 7.4+ and MySQL are active.

3. **Database Configuration**
    * Import the SQL dump into a database named `porsche_school`.
    * Update your database connection file with your local `root` credentials.

4. **Access**
    * Open ` http://127.0.0.1:8000/` in your browser.
